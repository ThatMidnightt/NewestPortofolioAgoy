# Portofolio — Nalendra Yoga (ThatMidnight)

Website portofolio pribadi dengan tampilan **minimalis & clean** — berisi profil, riwayat pendidikan, keahlian, prestasi, dan kontak. Dibangun dengan HTML dan CSS murni (tanpa framework), plus sedikit JavaScript untuk navigasi mobile dan animasi reveal.

## Fitur

- **Hero** — Perkenalan singkat dengan foto profil dan tagline
- **About** — Riwayat pendidikan (timeline) & keahlian (chips)
- **Projects** — Featured project: **Nodex**, web-based word processor
- **Achievements** — Penghargaan, prestasi, dan sertifikasi (termasuk Kaggle Intro to Python)
- **Contact** — Link email, WhatsApp, dan Instagram
- **Email form** — Halaman `Email.html` dengan form kontak (Formspree)
- **Responsif** — Nyaman di desktop, tablet, dan mobile
- **Aksesibel** — Skip link, focus state, `aria` labels, dukungan `prefers-reduced-motion`

## Teknologi

- HTML5
- CSS3 (vanilla, custom properties)
- Google Fonts — Space Grotesk & Inter
- Formspree (form kontak)
- Sedikit JavaScript vanilla (menu mobile, reveal on scroll, tahun otomatis)

## Struktur File

```
PortofolioAgoy/
├── index.html      # Halaman utama portofolio
├── style.css       # Styling custom halaman utama
├── Email.html      # Halaman form email
├── Email.css       # Styling halaman email
├── README.md
└── img/
    ├── ident3.png
    └── project/    # Gambar prestasi & project (versi optimized)
```

> `index2.html` dan `testing.html` adalah file eksperimen lama yang tidak dipakai — aman dihapus kalau sudah tidak diperlukan.

## Cara Menjalankan

1. Pastikan folder ini berada di `C:\xampp\htdocs\PortofolioAgoy`.
2. Jalankan **Apache** lewat XAMPP Control Panel.
3. Buka `http://localhost/PortofolioAgoy` di browser.

Bisa juga langsung membuka `index.html` di browser tanpa server.
